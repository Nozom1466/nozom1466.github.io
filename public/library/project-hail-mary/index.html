挽救计划

4.5
book

故事主要讲述了地球科学家 Grace 和 波江座外星人工程师 Rocky 因想要拯救自己星系恒星免于噬星体威胁，在鲸鱼座τ星相遇并互相帮助拯救两个星系的故事。

Grace 的科学家兴趣是推动整个剧情的重要动力。不论是在地球上对于噬星体的研究还是在鲸鱼座τ星与 Rocky 飞船的对接、探索噬星体的解决方法，作为科学家的一员，Grace 始终保持着科学探索的热情与动力，并且不断尝试使用科学的概念和方法解决眼前的问题。读小说的时候，我时常佩服于 Grace 的乐观思维——即使是在家园生死未卜、资源面临枯竭、孤身一人的情况下——他总是能把手头的研究工作进行下去，这可能是属于科学家的一种精神信仰吧。

Grace 和 Rocky 的合作可以说是另外一大卖点，不同星系族群的工程师与科学家联手解决两个种族的问题，给人带来天下大同的人文美感。我认为二者的合作可以看作是一次非常完美的巧合，首先二者都是因为相似的拯救任务来到了鲸鱼座τ星，并且需要解决的目标是同一个棘手的问题——找到噬星体的天敌，这种相似的使命感不仅能够促进二者的合作，并且加强了相互之间的身份认同。另外是技能上的互补，一位是科学家而另一位是工程师，所以二者合作能够顺利的推进合作，也为计划成功埋下伏笔。客观条件的允许让合作成为可能，但是真正的开展合作的过程还是看参与的人是否能够和睦相处、脾气相投。而在 Grace 和 Rocky 的性格特征就是合作成功的典型样例，二者因为目标的相似具有身份认同感，而都又因为只有孤身一人，产生了合作的可能，同时也让二者具有更高的同理心。孤独宇宙中能看到另一个生物已经是幸运的事，更何况这个生物也是有情感、能表达、能体恤对方情感的高级智慧生物。Rocky 跳出压力球拯救 Grace，Grace 最后又折返拯救 Rocky，虽然有一种设计的感觉在，但是真的能看到这种利他表现的时候还是让人感动。

另一个让我印象深刻的是 Grace 和 Rocky 第一次接触时，二者竭力想要用各种方式进行交流的场景。我还记得 Rocky 给 Grace 拿出两条代表着氧气和氨气的项链，甚至还有 29 倍气压的表示。后续经过频谱分析的方式解析出了更多语言，产生了第一台英语-波江语的翻译器。通过这台翻译器甚至能够进行科学术语交流。

除了感觉新奇之外，我觉得不同文化（星球文化！）的符号体系之间的相似度也让人惊奇。实际上我们会想到地球上不同文明之间的科学交流，从度量衡到抽象的科学概念，所有语言的源头其实是现实世界的物理规律。语言作为沟通的媒介承载了不同文明对于现实世界的理解，其确实在沟通中产生了重要的作用；但是不可忽视的一点是，我们想要交流的是关于现实世界的理解，而语言仅仅是一个工具。这让我想到了三体星人通过思维直接进行交流的沟通方式，这可能是更加本质意义上的交流。语言这种工具仍可以被优化，更接近描述世界的本质。突然想到 latent reasoning 相关的内容，我们想要去做一些 latent space communication/reasoning，实现 agent 之间更加高效的沟通方式，这也许真的是一个有意思的发展方向。如果发散一点想，现在 LLM 的范式仍旧是基于文本的序列预测，即使是多模态模型也是将连续的空间信息转化为离散的 token 表示，是否有一种更加适合 model 的世界表征，能够优化语言甚至代替语言完成描述世界这个本质任务？现在一些 neuron model 和 JEPA 之类尝试可能已经走在了路上。

最后不得不提一些小说中有意思的观点：不如说地球人与波江星人为什么发音频率相似？因为这个频率左右正是捕食者与物理世界交互时产生的声音，比如说摩擦地面的声音与撞击的声音等。而为了躲避追捕，我们的发音以及听觉都在适应这个频率，所以会在相似的频率段；比如说为什么地球和波江星的科技水平相似，并且二者会在这里相遇，这可能是因为如果过于落后，则无法建造飞船；如果过于超前，也不用担心噬星体的问题，能够在自己的星系里自行解决这个问题……等等如此的思维实验也是让我持续读下来的原因。

不过如果让我来以我的科幻阅读经历来评价的话，三体里边叙述的黑暗丛林法则以及相关的宇宙社会学概念更对我的胃口一点。挽救计划中二者的合作总是让我觉得有一种不真实感，不过整体小说是非常引人入胜的，所以还是十分推荐阅读。

后来发现这位作者居然就是 火星救援 的作者，马特达蒙的大脸海报我还记忆忧新，作者的想象力和写作功力真的让人感慨。
