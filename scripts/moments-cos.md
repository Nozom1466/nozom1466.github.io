# 此刻：浏览器直读 COS

## 工作方式

手机闪念完成 S3 同步后，网页刷新直接检查 COS 的 `SnapNote_Sync/index_shards/`。没有 `blog` 或 `review` 标签的笔记默认进入此刻，不要求添加 `threads`；归档、锁定、删除的记录仍不展示。不启动 GitHub Actions，不需要云函数，不在网页中放置密钥。正式 blog 文章和 review 书馆评价另由每 30 分钟定时任务生成，见 `snapnote-blog/README.md`。

分片索引的行格式为 `[uuid, deleted, lastModifiedMs, vectorClock, revisionId]`。正文通过索引指定的不可变版本读取，不通过列举全部正文猜测最新版本。列表按索引的最近修改时间排列，卡片日期显示正文的创建时间。同一 UUID 冲突时优先最新修改时间；同时间优先删除标记，再以版本 ID 确定顺序。这不是闪念多设备冲突合并算法。

每页最多 20 条可展示正文，页面最多保留 5 页。索引使用 ETag 重用未变分片，正文有 100 条 / 16MB 的内存缓存；刷新时合并重复请求，3 秒内复用刚完成的索引检查。每次打开网页仍需读取所有小型索引分片，但不下载全部正文和附件。图片懒加载，当前直接读取原图，不再自动生成小型 WebP；页面方形预览不等于文件被压缩。

## COS 配置

桶：`snapnote-test-1316371247`，上海。

保持桶 ACL 私有读写；使用同目录 `moments-cos-public-policy.json`，仅允许匿名列举索引目录及读取索引、正文、附件三个目录。其他目录不公开，原手机写入权限保持不变。网页隐藏删除、锁定、归档和加密记录，仅是展示规则，不是权限边界：上述公开目录内的原始字段、历史版本、尚未清理的删除内容仍可能被读取。

CORS 来源：`https://nozom1466.github.io`，本地验证可添加 `http://127.0.0.1:4181`。方法 GET / HEAD，允许头 `*`，缓存时间 600 秒。CORS 不提供身份认证。配置前必须确认公开范围，不能将写入密钥写入前端。

## 验证与切换

测试：`node --test scripts/moments-cos.test.mjs` 和 `node scripts/moments-render.test.mjs`。

Hugo 参数 `momentsFeedMode` 为 `cos`。工作流在推送或手动运行时构建博客，也定时检查 blog 文章变化；不读取 COS secrets，不再定时生成此刻快照。旧快照脚本保留作参考，未启用。加密索引分片跳过，其内记录不可展示；没有在浏览器内尝试解密。

手机尚未完成上传、COS 列表短暂不一致或网络缓存均可能导致延迟；读取失败时显示错误，不把失败当作“暂无记录”。视频、音频等未支持内容保持原有提示，不宣称已适配。
