# 此刻：本地集成预览

本次仅本地开发，不提交或推送。`/moments/` 复用主站 NexT 导航、字体和主题切换。

## 启动

1. 保持已有 COS 预览服务 `http://127.0.0.1:4178` 运行且已连接专用密钥。密钥只存在该服务的内存中；主站仓库不保存密钥、笔记快照或私人附件。
2. 在仓库启动 Hugo：`hugo server --bind 127.0.0.1 --port 1314 --baseURL http://127.0.0.1:4179/ --appendPort=false --disableLiveReload --renderToMemory`。可设置 `HUGO_RESOURCEDIR` 和 `--cacheDir` 为仓库外缓存路径，避免改变已有生成文件。
3. 另开终端运行 `node scripts/moments-preview.mjs`。
4. 打开 `http://127.0.0.1:4179/moments/`。手机同步完成后点击刷新图标或刷新页面。

## 范围与限制

本机桥接只允许读取笔记和附件，不提供密钥配置或写入接口，不开放跨域访问。正式构建现已支持静态分页数据，配套的每 15 分钟 GitHub 同步流程见 `scripts/moments-sync/README.md`，尚未推送启用；不能把专用密钥写入前端。Hugo 开发服务器继续使用原有实时读取模式。

沿用已验证的闪念正文渲染器（文字、方形图片/大图、200 字展开、表格、公式、待办）。KaTeX 从已有独立预览复用，保留其许可文件。未新增评论功能。跳过加密/不支持记录的计数不再展示，真正的连接错误仍显示。

适配器对 index_shards 的独立删除墓碑和多设备冲突尚未验证；正式公开发布前还需明确公开记录标记，不能直接公开整个私有同步空间。

## 分页与缓存

首屏 20 条，接近底部自动加载下一页，也保留“加载更多”按钮。页面只保留最近浏览的 5 页（100 条），可通过“加载较新记录”向前浏览。刷新重新取得最新首屏；数据版本变化时旧游标会提示刷新，避免错位翻页。

本机读取服务在仓库外保存仅含文件名、ETag、时间、可见状态和附件名的索引，不保存正文或密钥。第一次建立索引需读取所有历史正文；之后刷新仍需列举整个目录，但只下载变化的记录及当前页缓存中缺少的正文。翻页不再扫描目录。正文缓存上限 32MB / 200 条，原图 48MB / 100 张，缩略图 16MB / 300 张；超过容量时淘汰最久未用项。

列表按需读取最长边 384px 的 WebP 缩略图，点击查看原图。缩略图在本机生成，不覆盖 COS 原图；首次处理仍需从 COS 下载原图。图片使用 5 分钟浏览器缓存及 ETag。独立预览服务升级重启后需重新输入专用密钥；当前索引不依赖密钥内容。

验证：`node scripts/moments-render.test.mjs`；独立读取服务目录执行 `npm test`（包含 20,000 条模拟数据的分页、增量读取、索引重启、缓存容量和缩略图完整性测试）。未执行真实两万条 COS 压力测试。
